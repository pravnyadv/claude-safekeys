# Security

safekeys is a privacy tool: a bypass that lets a key reach the transcript, the prompt history or the model is a security bug.

Report one privately through GitHub: the **Security** tab, then **Report a vulnerability**. Please do not open a public issue with a working bypass. Include the Claude Code version, the safekeys version, the prompt or command you used, and where the key showed up.

What counts as in scope, and what doesn't, is listed under "What it protects, and what it doesn't" in the README.
